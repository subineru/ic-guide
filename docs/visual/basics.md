## 第 1 步 · 電壓、電流、電阻(水管比喻)
| 元素 | 畫法 | 意義 |
|---|---|---|
| 水槽與水位 | 左側的槽,藍色水位高度 = 電壓滑桿 | 電壓像水壓;水位越高壓力越大 |
| 水管 | 由槽向右的管子 | 電流的通路 |
| 管中的橘色擋塊 | 上下各一塊,滑桿越大擋塊越高、通道越窄 | 電阻像管子的狹窄處 |
| 紫色虛線與箭頭 | 沿管子由左向右移動;越粗越快 = 電流越大 | 電流(水量) |
| 底部橫條 | 紫色填滿的長度 = 電流大小 | 電流大小 |

數量關係(`domain/sim/ohm.js`,有單元測試):電流 = 電壓 ÷ (5 × 電阻),全部是 0~1 的「畫面大小」,不是真實單位。電阻有下限,管子不會完全關死。
**只畫「電流」(由左到右),不畫電子**;電流方向與電子實際移動方向相反,本章不談,已列入簡化聲明。

## 第 2 步 · 半導體可以被控制
三條水管:**導體**(一直有流動)、**絕緣體**(中間是一堵實心牆,完全不流)、**半導體**(中間有閥門,由「控制」滑桿決定開多大,流動量隨之改變)。右側文字「一直導電 / 不導電 / 可以被控制」與形狀同時表達。
**限度**:閥門只是比喻,真實半導體不是機械閥;為什麼能被控制(N 型、P 型、PN 接面)留給延伸步驟。

## 第 3 步 · 用電壓當開關
左側「控制電壓」直條(紅色填滿高度 = 控制電壓,中線為示意的門檻);中間是開關(控制電壓過門檻時槓桿放平、接通,否則翹起);右側燈泡(接通時發亮、線上有電流虛線)。虛線由控制條指向開關,表示「控制電壓決定開關」。
**限度**:真實電晶體是連續控制,這裡只看「通」與「斷」兩端;門檻位置是示意。

## 運動語意
每個動畫都對應該步驟的一句話:第 1 步水位與擋塊移動對應「電壓、電阻改變時電流跟著變」;第 2 步閥門開合對應「半導體可以被控制」;第 3 步槓桿與燈泡對應「電壓決定通或不通」。沒有純裝飾的移動(手繪抖動除外)。

## 簡化聲明(待審閱者確認)
1. 水管比喻只說明三者關係,不解釋電場與電荷的真實行為。
2. 所有數量都是示意的畫面大小。
3. 只畫電流,不畫電子。
4. 第 3 步的開關、門檻是示意。

## 無障礙
色彩不單獨傳達意義:水量以「虛線粗細與速度」、擋塊以「位置與高度」、閥門以「開口大小」、控制電壓以「條的高度」表達。可暫停、單步、調速;「降低動態」時關閉手繪抖動。
