## 共同的畫法規則
- 上方粗紅線 = **高電壓**,下方粗綠線 = **低電壓(地)**;輸出節點用實心圓點表示。
- 開關畫成兩個接點加一根槓桿:**接通 = 槓桿放平(貼住兩個接點)**,**不通 = 槓桿翹起**。每個開關旁邊寫明它在什麼條件下接通。
- 輸入與輸出用圓形徽章顯示 **0 或 1**:數字、顏色(1 = 紅、0 = 綠)、輸出線的粗細(1 較粗)**同時**表達,不只靠顏色。
- 輸出線顏色與粗細、徽章數字,都來自模型算出的結果,不是手寫對照。
- **不畫輸入到輸出的連線**:輸入只「控制」開關(以文字標明),並沒有接到輸出;這是刻意的,避免誤導。
- 真值表在畫面一角,目前的輸入組合那一列以底色標出。

## 第 1 步 · 反相器
一個開關在上(輸入 0 時接通,連到高電壓)、一個在下(輸入 1 時接通,連到低電壓),輸出取自中間的節點。輸入 0 → 上方接通 → 輸出 1;輸入 1 → 下方接通 → 輸出 0。**任何輸入下恰好一個方向接通**(單元測試驗證,不會浮接也不會短路)。

## 第 2 步 · NAND 閘
上方兩個開關**並聯**(A=0 接通、B=0 接通,任一個接通輸出就是 1);下方兩個開關**串聯**(A=1 接通、B=1 接通,**兩個都接通**輸出才接到低電壓,得到 0)。四種輸入組合都由畫面實測驗證(端對端測試逐一切換並比對輸出)。

## 運動語意
步驟自動播放時依序切換輸入組合並停留,讓你看到「哪個開關接通、輸出變成什麼」;也可用「輸入 A / 輸入 B」開關手動試。沒有純裝飾的移動。

## 簡化聲明(待審閱者確認)
1. 電晶體畫成機械式的開關,只表現「接通 / 不通」。
2. 「0＝低電壓、1＝高電壓」是示意,不代表具體伏特數。
3. 上拉是 P 型、下拉是 N 型的互補結構,本章不使用 N/P 的名詞(留給電晶體章)。
4. 目前只做反相器與 NAND;正反器與移位暫存器之後補上。
5. 「0 與 1」暫時在本章定義,之後移到「數位與二進位」章。

## 無障礙
色彩不單獨傳達意義(數字、線粗細、槓桿位置同時表達)。可暫停、單步、調速。
