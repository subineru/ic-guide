# 視覺規格:首頁主線動畫(home-overview)

狀態:**待審**(未經 IC 專業審閱)。保真等級:**L1 示意**(關係與順序正確,形狀與比例不代表實際波形)。圖上與頁面皆標示「示意」。

## 這個動畫要說什麼(一句話)
一筆資料從手機傳來,依序經過驅動 IC 的 6 個零件,**在位準轉換變成較高電壓、在 DAC 變成類比電壓、在緩衝器變得有力氣**,最後讓面板上的一個像素亮起。

## 元素
| 元素 | 形狀 | 意義 | 備註 |
|---|---|---|---|
| 封包(低電壓數位) | 4 根短/中的綠色小條 | 一串 0 與 1(短=0、中=1),電壓低 | 介面傳輸 → 位準轉換 |
| 封包(較高電壓數位) | 4 根短/**高**的紅色小條 | 同樣的位元,電壓變高 | 位準轉換 → DAC |
| 封包(類比電壓) | 一條細的紫色波形 | 一個連續的電壓,不再是 0/1 | DAC → 緩衝器 |
| 封包(有力氣的電壓) | 一條粗的紫色波形 | 同一個電壓,已能驅動長長的資料線 | 緩衝器 → 面板 |
| 方框發光 | 方框外圈亮起約 0.5 秒 | 封包剛到達該零件 | 發光時間與封包位置一致 |
| 像素 | 面板方框右下角的小方塊,由灰變黃並發光 | 一個像素亮起 | 保持約 2 秒後熄滅 |

形狀差異(短/高、細/粗、方條/波形)與顏色**同時**表達,不只靠顏色。圖例固定顯示在動畫上方,並與動畫使用同一份元素。

## 運動語意
- 封包沿主線下方的軌道由左到右移動,**速度固定**(時間與沿路距離成正比);全程約 8.8 秒,像素亮約 2 秒,一輪 12 秒後重複。
- 封包的形態只在「位準轉換、DAC、緩衝器」三處改變,對應 `curriculum.js` 的 `signal` 欄位(有單元測試:順序只能前進 低 → 高 → 類比 → 有力氣)。
- 動畫不做純裝飾;沒有任何與資料流無關的移動。

## 簡化聲明(待審閱者確認)
1. 波形、位元長度、顏色都是示意,不代表真實訊號或電壓。
2. 省略時序控制、影像記憶體、影像處理、電源產生等方塊。
3. 「位準轉換之後電壓較高、DAC 之後變類比、緩衝器之後有力氣」是本教材的簡化主線。
4. 面板端只表現「像素亮起」,不區分液晶或 OLED。

## 無障礙與效能
- 可暫停/播放(按鈕);「降低動態」開啟時不播放,直接顯示亮起的像素。
- 地圖離開畫面時自動暫停;只動畫 `transform` 與 `opacity`。
- 窄螢幕沿清單左側的紫色線由上往下移動,規則相同。
